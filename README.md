# Présentations

Diapos reveal.js, servies par GitHub Pages.

- `dinum-sda.css` + logos : thème commun.
- Une présentation = un dossier avec un `index.html` (copier `index.html`). Contenu en Markdown dans le `<textarea data-template>`, diapos séparées par `---`, schémas en `<pre class="mermaid">`.
- Aperçu local : `npx http-server . -c-1` puis ouvrir le dossier voulu.
- PDF : ajouter `?print-pdf` à l'URL et imprimer en PDF.

⚠️ Dépôt public : aucune donnée interne.
